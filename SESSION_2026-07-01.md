## Approval count bug (recon + fix)

**Observed:** Dashboard showed 5 pending (header, APPROVALS card, NEEDS REVIEW); Content Pipeline REVIEW and Agents Command Center showed 0 at the same timestamp.

**Cause:** Stale `daily_digests.approvals` JSON + `Math.max(digest.length, liveCount)` on `MorningDigest`; live surfaces counted `agent_tasks` while digest listed already-approved items.

**Fix:** Single helper counting `agent_outputs.status = 'pending_approval'`. Dashboard brief uses server-fetched live count/list, not cached digest rows.

**Verify live:**

```txt

After approve all → all show 0; "Queue is clear" on dashboard + agents together
```
