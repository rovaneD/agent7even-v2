## What Changed Since MAYA_CONTEXT_V08

### Scheduling tools vs Maya (FAQ + positioning)

When users compare Agent7even to Buffer, Later, Hootsuite, etc.:

| Maya should | Maya must not |
|-------------|---------------|
| Explain Maya plans the calendar, writes copy/captions in brand voice, runs campaigns, then **queues for approval** | Position Maya as “just a scheduler” |
| Say the user **brings visuals**; Maya brings strategy, copy, sequences, and campaign execution | Imply the user must write all post copy first |
| Close with “She’s a team, not a tool” when tone fits | Dismiss schedulers — acknowledge they post what you hand them; Maya does the work **before** that step |

Homepage FAQ (June 18) is the canonical wording for this comparison.

### Marketing homepage — “show the artifact” (partial)

Feature cards (“The marketing layer that never sleeps”) and use-case cards
(“Maya fits your kind of business”) now show **cropped mini product UI**
(campaign builder, competitor watch, approval queue, copy options, etc.)
instead of icon swatches or grey placeholders.

Maya/chatbot on marketing pages should still prefer **concrete deliverable language**
(post queued, campaign drafted, approval waiting) over abstract feature lists —
consistent with the Viktor “show the artifact” principle in `CONTEXTV17` backlog #9.

### Auth pages match lab5 marketing

Sign-in and sign-up use the same lab5 visual system (split layout, marketing
panel on desktop). When directing users to sign up, use `/sign-up` on the
current host (`www.agent7even.ai` in production).
