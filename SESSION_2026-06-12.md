## Zernio analytics investigation

### Root causes found

1. **`/analytics` vs `/posts` split** — External IG posts (Alex, `isExternal: true`)
   in analytics; Zernio composer publishes in `/posts` only. Native publishes
   may never appear in analytics (or lag).
2. **Butterflies test post** — Quick Zernio publish test; deleted on Instagram and
   via Zernio UI; still ghosted in `GET /posts/:id` briefly; not in analytics.
3. **Best-post URL** — Zernio sometimes stale at top-level `platformPostUrl`;
   fixed by preferring `platforms[]` row. Live API returns correct Alex URL.
4. **“Random post” on View link** — **Chrome cache** of old deploy/API responses.
   Fresh Safari (mobile + desktop) opened correct reel. Fix: hard refresh / clear
   site data; client now uses `cache: 'no-store'` on analytics fetch.
