# SESSION_2026-07-14 — Critical bug investigation

## Scope

Reviewed recent behavioral commits with a high-severity bar: data loss,
crashes, security holes, and significant user-facing breakage. The audit traced
the July 13 profile-resolution/dead-route changes and recent Foundation,
approvals, billing visibility, marketing chat, team, and Zernio changes.

## Confirmed bug

Commit `9080b76` changed Foundation rescore persistence from upsert to:

1. delete every `foundation_field_scores` row for the profile;
2. insert the replacement rows.

The operations were not transactional and neither error was checked. A failed
insert after a successful delete therefore wiped all per-field scores while the
route continued to update the profile and returned HTTP 200. The missing rows
also made the generation floor return `no_scores`.

## Fix

`app/api/foundation/score/route.ts` now upserts the replacement set first, then
deletes only stale historical field keys. Read, upsert, prune, and profile
update errors return HTTP 500. The critical failure mode now preserves the
previous score rows.
