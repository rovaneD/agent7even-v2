# SESSION_2026-07-16 — Critical bug investigation

*Experimental v2 (`rovaneD/agent7even-v2`).*

## Finding

Recent commit `6b53042` introduced a destructive side effect in
`/dashboard/agents/approvals`: every Server Component render called
`reconcileOrphanedPendingApprovalOutputs()`, which changed pending outputs to
`rejected` when their task row was absent or had a different workspace
`user_id`.

Concrete triggers included legacy team rows split between member and owner
profile IDs, incomplete profile merges, and genuine dangling task references.
Opening Approvals—or its automatic 45-second refresh—silently removed those
paid outputs from review. Because the final update did not require
`status = 'pending_approval'`, it could also overwrite a concurrent approval.

## Fix

Commit `22c3c13`:

- removed reconciliation from the Approvals page render path;
- deleted the unused destructive reconciliation helper;
- preserved read-only queue/count behavior that ignores rows without visible
  tasks.

No database cleanup was run and no production data was changed.

## Validation

```bash
npx tsc --noEmit
npm run build
```

Both passed. Repository search found no remaining reference to
`reconcileOrphanedPendingApprovalOutputs` or its synthetic rejection message.
